مشروع «مواقيت الصلاة»
=====================

الملفات
-------
- index.html: بنية الصفحة العربية.
- styles.css: التصميم المتجاوب.
- app.js: تحديد الموقع، طلب المواقيت الحقيقية، وعرض العدّاد.
- README.txt: تعليمات التشغيل.

طريقة العمل
-----------
1. يطلب الموقع مواقيت الصلاة من AlAdhan API عبر:
   https://api.aladhan.com/v1
2. طريقة الحساب الافتراضية هي رقم 3: رابطة العالم الإسلامي (MWL).
3. هذه الطريقة ليست تأكيدًا بأن النتائج مطابقة للتقويم الرسمي الليبي؛ يمكن أن تختلف المواقيت الرسمية المحلية.
4. لا توجد مفاتيح API سرية أو اشتراك مدفوع في هذا المشروع، لكن يلزم الاتصال بالإنترنت لاستخراج المواقيت.
5. يبدأ الموقع بطرابلس، ويمكن اختيار مدينة ليبية أخرى أو استخدام GPS.

التشغيل على الهاتف
------------------
- يمكنك فتح index.html محليًا لتجربة الواجهة، لكن بعض المتصفحات قد تمنع تحديد الموقع في الملفات المحلية.
- للحصول على GPS، ارفع الملفات إلى استضافة HTTPS.

استضافة مجانية على GitHub Pages من الهاتف
-----------------------------------------
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع الملفات الأربعة إلى جذر المستودع، وليس داخل مجلد إضافي.
3. افتح Settings ثم Pages.
4. في Build and deployment اختر Deploy from a branch.
5. اختر الفرع main والمجلد /(root)، ثم Save.
6. انتظر حتى يظهر رابط الموقع، وافتحه باستخدام HTTPS.

الخصوصية والأذونات
------------------
- لا يُطلب الموقع الجغرافي إلا عند ضغط المستخدم على زر تحديد موقعي، وبعد موافقته.
- لا توجد قاعدة بيانات أو حسابات مستخدمين أو إعلانات.
- إحداثيات GPS تُرسل إلى AlAdhan API من المتصفح لحساب المواقيت.

ملاحظات تقنية
-------------
- يجب أن يكون الهاتف متصلًا بالإنترنت لتحديث المواقيت.
- عند فشل طلب API تظهر رسالة وخيار إعادة المحاولة بدل عرض مواقيت ثابتة على أنها حقيقية.
- يعتمد التاريخ المعروض على بيانات AlAdhan، بينما تُستخدم ساعة الجهاز للعدّ التنازلي. الأفضل ضبط ساعة الهاتف والمنطقة الزمنية بشكل صحيح.
- المدن الليبية في القائمة تستخدم إحداثيات جغرافية تقريبية للمدينة، وليست عنوانًا دقيقًا.


أيقونة الموقع:
- favicon.svg: أيقونة الموقع التي تظهر في تبويب المتصفح.
- manifest.webmanifest: بيانات تساعد عند إضافة الموقع إلى الشاشة الرئيسية على الأجهزة المدعومة.
